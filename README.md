# 小爱音乐台 · 在线点歌台

一个网易云音乐风格的网页点歌台，打开固定网址即可用它控制家里的小爱音箱播放电脑上的歌曲。

## 在线网址

https://zhenyu20001120-hub.github.io/xiaoai-music/

## 工作原理

小爱音箱和歌曲文件都在你自己的电脑上，GitHub 只托管网页界面本身。网页通过一个运行在本机的桥接服务，跨域调用本机的 Songloft 服务，进而控制小爱音箱。

    GitHub Pages 网页  --(跨域)-->  本机桥接服务 :58092  -->  Songloft :58091  -->  小爱音箱

## 使用前准备（只需一次）

1. 本机保持「打开小爱音箱」服务在运行（已有开机自启）。
2. 本机保持桥接服务 `bridge.py` 在运行（监听 58092 端口）。

## 更新方式

网页界面代码在 `web/index.html`。修改后推送到 GitHub，几分钟内在线网址自动更新，无需改动本机任何文件。

## 换网络 / 换电脑

桥接地址默认取 `http://当前主机名:58092`。若运行服务的电脑 IP 变化，可点击页面右上角「本机连接」按钮修改，或用网址参数 `?bridge=http://192.168.x.x:58092` 指定，设置会被浏览器记住。
